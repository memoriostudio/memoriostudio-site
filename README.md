# memoriostudio.com

The public website of **Memorio Studio LLC**, a Wyoming limited liability company.

Static HTML and CSS. No JavaScript, no build step, no dependencies, no third-party
requests. Served by GitHub Pages from `main`.

Security contact: `contact@memoriostudio.com` — see
[the disclosure policy](https://memoriostudio.com/security.html) and
[`/.well-known/security.txt`](https://memoriostudio.com/.well-known/security.txt).

Deployment and DNS are documented privately. Everything committed here is served
at the site root and is world-readable by design; nothing operational belongs in
this repository.
